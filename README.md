# Proyecto-Sprint7---Herramientas-de-desarrollo-de-Software
Creación y gestión de entornos virtuales de Python y el desarrollo de una aplicación web.

El Proyecto busca crear un link web donde se puede visualizar informacion del data set de carros. 

Link al pryecto: https://proyecto-sprint7-herramientas-de.onrender.com


EL repositorio consta de
    Archivo readme: Url a la aplicacion Render , descripcion clave del proyecto
    Vehicles_US.csv: Data set del proyecto
    requirements.txt: Archivo con libreias enecesarias para correr el proyecto
    Notebooks:
        - EDA: Carga del de los datos opara convertir en df, analisis exploratorio del df, prueba de creacion histogramas, driagramas de despersion y tablas resumen para el aplicativo

    cuador-de-mandos.py: Aplicativo de python para correr en redner. Generar histograma de los odometros, diagramas de dispercion en precio de vehículo por odometro y tablas de resumen de top 5 modelos con precios promedio más costosos y los Top 5 modelos con odometro promedio más almás alto

Pasos para correr la aplicacion:
- Acceder al link URL  https://proyecto-sprint7-herramientas-de.onrender.com
- Generar graficas con los botones
- Generar tablas con los checkboxes
